# AI Tools Hub Clipper（Chrome 扩展）

一键从当前网页提取信息，编辑后存入你的 AI Tools Hub，自动新建卡片。

## 功能

- 点击图标，自动从当前页面提取：名称、简介、链接、预览图、favicon、来源域名。
- 弹窗中可手动修改任意字段、选择卡片类型、加标签、设星标。
- 「抓取预览图」按钮调用服务端 Microlink 补抓预览图与简介。
- 一键保存，调用 `POST /api/cards` 新建卡片。

## 安装（开发者模式加载）

1. 打开 Chrome → 地址栏输入 `chrome://extensions`。
2. 右上角开启「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择本目录 `extensions/chrome`。
4. 固定图标到工具栏。

## 配置

首次使用点图标右上角「设置」，或在扩展页点「详情 → 扩展程序选项」：

- **服务器地址**：
  - 本地调试：`http://127.0.0.1:7317`
  - 公网部署后：你的火山引擎域名，例如 `https://hub.example.com`
- **API Token**：与服务器 `.env` 里的 `EXTENSION_API_TOKEN` 一致。
  - 服务器没设 token 时（仅本地）可留空。
  - 公网部署必须填写，否则写接口返回 401。
- **默认卡片类型**：从服务器读取，新建卡片时的默认选项。
- **主题**：和工作台同款的 6 套主题。
  - 「自动跟随工作台」：读取你**已打开的工作台标签页**当前主题并套用；读不到时用上次同步过的主题，再不行用默认 Ardoise。
  - 也可固定选某一套。

点「测试连接」确认能读到卡片类型，再「保存设置」。

## 工作原理

```
扩展弹窗 → (HTTPS + Bearer Token) → AI Tools Hub 的 Next.js API → MySQL
```

- 页面信息在浏览器本地提取（读 DOM 的 og/meta/favicon），**支持需要登录或内网的页面**。
- 扩展从不直接连数据库，只调用应用 API。
- 读接口公开，写接口（建卡、抓预览图）需要 Token（同源的网页后台不受影响）。
- 主题：工作台主题存在浏览器 localStorage，扩展通过读取已打开的工作台标签页来同步。

## 部署到火山引擎 + 宝塔时

1. 服务器 `.env` 设置 `EXTENSION_API_TOKEN`（用 `openssl rand -hex 32` 生成）。
2. 宝塔用 Node 项目 + PM2 跑应用，Nginx 反代并开启 SSL（建议 HTTPS）。
3. 扩展设置里把「服务器地址」改成公网域名，「API Token」填同一串。

## 已知限制

- 当前为 v0.1：无右键菜单快捷保存、无批量保存。
- 鉴权为「同源放行 + 跨源需 Token」，可挡住浏览器跨站滥用；如需更严格（防 curl 伪造）后续可升级为全量写鉴权。
